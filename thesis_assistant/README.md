# 学位论文研究与规范编排助手

该项目现包含两部分：

1. **Python 服务原型**：用于多模型路由、预算控制、章节草拟与规则校验。
2. **网页原型（仿专业论文服务站点风格）**：用于展示完整产品交互体验。

## 功能覆盖

- 多模型 API 切换与预算控制
- 论文框架规划（问题定义/原理分析/方法/实验/结论）
- 基于资料摘要的章节草拟
- 图、表、公式自动规范化建议
- 引用可追溯性与结构完整性检查
- 按 GB/T 7713.1—2025 规则底座进行合规提示（替代 2006 版）
- 导出 Word/PDF（MVP 阶段为占位能力）

## 快速体验网页原型

```bash
cd thesis_assistant/web
python -m http.server 8080
```

浏览器打开：`http://localhost:8080`

## 运行 Python 命令行原型

```bash
cd thesis_assistant
PYTHONPATH=src python main.py \
  --topic "多传感器融合下轮腿机器人运动控制研究" \
  --materials "文献A摘要" "文献B实验数据说明" \
  --budget 3.0
```

## 学术合规原则

- 最终论文内容必须由作者确认。
- 所有关键结论必须有来源、可追溯、可复核。
- 系统输出仅作辅助，不替代作者的学术责任。
