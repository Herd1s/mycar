# 轮腿式平衡机器人代码分析报告

## 1. 项目概述
该项目是一个关于轮腿式平衡机器人（或类似倒立摆机构）的控制与仿真项目。核心算法采用了LQR（线性二次调节器）控制，并实现了增益调度（Gain Scheduling）策略，以适应机器人腿长变化带来的动力学特性改变。

## 2. 文件详细分析

### 2.1 核心仿真模型
*   **文件名**: `blance_leg.slx`
*   **类型**: Simulink 模型文件
*   **作用**: 包含机器人的多体动力学物理模型、控制器逻辑以及环境设置。该模型接收由Matlab脚本计算出的控制增益矩阵 K，进行闭环控制仿真。

### 2.2 控制算法与增益计算
*   **文件名**: `get_k_length.m` (核心算法)
    *   **作用**: 计算特定腿长下的最优 LQR 控制增益矩阵。
    *   **原理**:
        1.  使用符号计算定义系统物理参数（质量、惯量、长度）和状态变量。
        2.  建立系统的非线性微分方程。
        3.  在平衡点进行线性化，求解状态空间矩阵 A 和 B。
        4.  定义权重矩阵 Q 和 R，计算 LQR 反馈增益 K。

*   **文件名**: `get_k.m` (离线计算与拟合)
    *   **作用**: 生成增益调度表。
    *   **原理**:
        1.  遍历腿长范围（0.1m - 0.5m）。
        2.  调用 `get_k_length` 计算每个长度对应的增益。
        3.  使用 `polyfit` 对增益矩阵的每个元素进行3次多项式拟合。
    *   **目的**: 将复杂的实时优化计算转化为简单的多项式函数，便于控制器实时查表或计算。

### 2.3 运动学解算
*   **文件名**: `d_phi0.m`
    *   **作用**: 五连杆机构运动学解算。
    *   **原理**:
        *   根据连杆长度和关节角度计算末端位置及虚拟腿长。
        *   计算雅可比矩阵 (Jacobian)，建立关节角速度与广义速度的关系。

### 2.4 文档生成辅助
*   **文件名**: `get_data.m`
    *   **作用**: 自动化生成说明文档。
    *   **内容**: 定义符号、含义、正方向的映射表，并自动写入 `符号说明表.xlsx` Excel文件中。

## 3. 开发流程总结
1.  **建模**: 使用 `get_k_length.m` 推导数学模型。
2.  **控制设计**: 通过 `get_k.m` 离线计算不同构型下的最优控制参数。
3.  **拟合**: 将控制参数拟合为关于腿长的函数。
4.  **仿真**: 在 `blance_leg.slx` 中载入参数进行验证。
